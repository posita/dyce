GraphType

Bases: StrEnum

Controls which variant of the distribution is plotted.

  • NORMAL: raw probability for each outcome
  • AT_MOST: cumulative probability \(P(X \le k)\)
  • AT_LEAST: survival probability \(P(X \ge k)\)

class GraphType(StrEnum):
    r"""
    Controls which variant of the distribution is plotted.

    - *NORMAL*: raw probability for each outcome
    - *AT_MOST*: cumulative probability $P(X \le k)$
    - *AT_LEAST*: survival probability $P(X \ge k)$
    """

    NORMAL = auto()
    AT_MOST = auto()
    AT_LEAST = auto()
